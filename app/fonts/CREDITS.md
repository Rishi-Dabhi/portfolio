# Portfolio fonts

The Latin WOFF2 files are the same Google Fonts assets previously downloaded by `next/font/google`. They are now committed locally and loaded with `next/font/local` so builds do not depend on Google Fonts responses or network availability.

- `inter-latin-variable.woff2`: Inter, upright variable font; the layout uses weights 400–700. Copyright 2020 The Inter Project Authors. [Upstream project](https://github.com/rsms/inter). See `Inter-OFL.txt`.
- `cormorant-garamond-latin-variable.woff2`: Cormorant Garamond, upright variable font; the layout uses weights 400–600.
- `cormorant-garamond-latin-italic-variable.woff2`: Cormorant Garamond, italic variable font; the layout uses weights 400–600. Copyright 2015 the Cormorant Project Authors. [Upstream project](https://github.com/CatharsisFonts/Cormorant). See `Cormorant-Garamond-OFL.txt`.

Both families are distributed under the SIL Open Font License 1.1. These are Latin subsets, covering the portfolio's current text and punctuation.

Original Google Fonts CSS requests:

- https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap
- https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,400;0,500;0,600;1,400;1,500;1,600&display=swap
